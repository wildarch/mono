Build a Python script to encrypt (and potentially transcode) audio files located in the `sources/` directory, in such a way that they can be decrypted and played using javascript in a regular (modern) browser.
The encrypted version of each file should be stored under a newly created `encrypted/` directory.

Also generate a sample html file that retrieves one of the encrypted files, then decrypts and plays them.

A python venv is available where you can freely install additional packages.
Run `source ~/workspace/venv/bin/activate` to load it.
